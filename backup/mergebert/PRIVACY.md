# Public export boundary

Only implementation, aggregate experimental results, configuration, sanitized reference notebook and a hand-written synthetic example are included.

Excluded: raw experimental code records, author/commit messages, sample identifiers, real timestamps, token/edit feature caches, merge intermediates, label-level audits, per-sample predictions, all pretrained/trained model binaries, optimizer states, local logs, machine manifests and absolute user paths. These remain in the original local reproduction folder.

Notebook execution outputs, execution counters and optional cell metadata were cleared. Public repository names in aggregate evaluation tables are retained for attribution and meaningful per-repository comparison; they are not author identities. Public model file hashes are retained for provenance.

The release scan checks secret-like strings, email/IP patterns, personal machine paths, disallowed artifact names/extensions and notebook outputs. This is an automated check plus an explicit file allowlist, not a guarantee that arbitrary future private files are safe. Runtime data is ignored by Git; rerun this review if expanding the public scope.
